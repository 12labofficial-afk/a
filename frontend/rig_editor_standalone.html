Rig Animation Editor

Kisi bhi real character file (.fla ya .ana.zip) ke real parts nikaal ke manually pose/animate karo. Sab kuch is browser ke andar hi chalta hai -- koi upload kisi server pe nahi jaata.

1. Character upload karo

Mobile pe do ungliyon se pinch karke zoom hamesha karte raho. Ek ungli se khaali jagah drag karke pan karne ke liye upar "Pan (1 finger)" ON karna padega -- default OFF hai, taki part ko pakadte waqt chuk jaane pe poora view/character accidentally hil na jaye.

● purple dot = root (jiska koi parent nahi), ● yellow = normal joint, ● red = is bone ka rotation asli rig mein disabled hai, arrow → hamesha parent se child ki taraf dikhata hai.

Parts

Part pe tap karke select karo, phir stage pe drag karke uska joint ke around ROTATE karo -- bones kabhi ek doosre se alag nahi honge, sirf angle badlega. Character ki poori body ki position hamesha FIXED rehti hai -- root part (jiska koi parent nahi) is mode mein drag nahi hota bilkul, wo apni jagah pe permanently locked rehta hai. Walk cycle jaisi animation banane ke liye bas haath-pair (limbs) hi ghumao.

    Is bone ka rotation asli rig mein disabled hai (rotationEnabled="false") -- slider phir bhi kaam karega, par original file isko rotate nahi karti thi.

    Rig Export

    "Move Parts" mode mein parts ko bones pe sahi se attach karne ke baad (ya kabhi bhi), current corrected rig ko real file mein wapas save kar lo -- usi ko baad mein dubara upload kar sakte ho.

    .ana export sirf tab milta hai jab original upload ek .ana bundle ho (seedhi .fla upload ke liye sirf .fla export use karo).
